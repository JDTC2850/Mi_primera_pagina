# Mi_primera_pagina

Mi primer repositorio:

Este repositorio contiene mi primer proyecto de desarrollo web utilizando las tecnologías básicas **HTML, CSS y JavaScript**.

El objetivo de este proyecto es aprender la estructura de una página web, aplicar estilos visuales y agregar funcionalidades básicas mediante programación.

---

## Descripción del Proyecto

Este proyecto consiste en la creación de una página web sencilla donde se implementan conceptos fundamentales del desarrollo frontend:

- Creación de una estructura HTML.
- Aplicación de estilos mediante CSS.
- Uso de JavaScript para agregar interacción con el usuario.
- Manejo de versiones utilizando Git y GitHub.

---

##  Tecnologías Utilizadas

Las tecnologías utilizadas en este proyecto son:

- *HTML5* → Para crear la estructura y contenido de la página.
- *CSS3* → Para diseñar y personalizar la apariencia visual.
- *JavaScript* → Para agregar funcionalidades e interacción.
- *Git* → Para controlar las versiones del proyecto.
- *GitHub* → Para almacenar y gestionar el repositorio.
